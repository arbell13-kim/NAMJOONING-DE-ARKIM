
# Mi espacio Namjooning 🌿

Aplicación personal para organizar actividades,
hábitos, aprendizaje, creatividad y descanso.

## Identidad visual

- Azul profundo: #526F87
- Azul cielo: #A9C1D0
- Azul niebla: #DCE8ED
- Verde salvia: #82998A
- Verde suave: #DCE5DA
- Marfil: #F2EEE6

## Frase de la aplicación

"Mañana quizás sea un poquito más sabio
y ese también seré yo".

## Estructura

- index.html: aplicación principal.
- manifest.json: configuración PWA.
- service-worker.js: caché y acceso sin conexión.
- logo.svg: identidad gráfica.
- README.md: documentación.

## Funciones actuales

- Registro de actividades.
- Seguimiento de hábitos.
- Agenda.
- Aprendizaje.
- Creatividad.
- Notas personales.
- Estadísticas.
- Exportación e importación de respaldos.

## Funciones en desarrollo

- Modo día de descanso.
- Instalación como PWA.
- Sincronización entre dispositivos.
- Cuenta personal y almacenamiento en la nube.

## Almacenamiento

La versión actual utiliza localStorage.
Los datos permanecen en el navegador del dispositivo.
La sincronización en la nube todavía no está implementada.

## Instalación y pruebas

La aplicación debe servirse mediante HTTPS
o localhost para utilizar el Service Worker.

No basta con abrir index.html directamente
mediante file:https://github.com/arbell13-kim/NAMJOONING-DE-ARKIM.git
